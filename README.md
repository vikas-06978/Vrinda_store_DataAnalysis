# Vrinda Store Admin Dashboard

This Excel dashboard transforms order data into clear, actionable insights for retail teams. I've built it to help you quickly understand customer patterns, track sales performance, and monitor delivery outcomes through interactive charts and simple filters.
## What's Inside

The dashboard contains interactive visuals that show how different products perform across age groups, genders, and sales channels. You can easily filter data to focus on specific regions, order statuses, or product categories. Everything updates automatically as you adjust the filters.
## Key Features

  - Gender and age analysis charts for customer demographics

  - Order status tracking across all sales channels (Amazon, Flipkart, Myntra, etc.)

  - Delivery performance breakdown by state and region

  - Detailed order data table with customer and product information

  - Easy-to-use filter panels for quick analysis

## How to Use

Open the Excel file and use the filter panels on the left to explore your data. Click on different categories, genders, or states to see how the charts change. The dashboard is designed to be intuitive no training needed.
## Perfect For

Store managers, sales teams, and anyone who wants to gain a deeper understanding of their business without getting lost in complex data analysis.

The dashboard makes it easy to spot trends, identify top-performing products, and pinpoint regions that require attention. Just click, filter, and discover.
